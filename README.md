# 🎬 NurAuto — AI YouTube Video Studio

Avtomatik YouTube video yaratish tizimi. Mavzu tanlashdan tortib YouTube'ga yuklashgacha — hammasi AI orqali!

## ✨ Xususiyatlar

- 🔍 **Kanal Tahlili** — YouTube kanalingizni AI orqali tahlil qilish
- 🎬 **Smart Video Yaratish** — Trend mavzular asosida video
- 🎙️ **AI Ovoz** — Turli tillarda tabiiy ovoz
- 🖼️ **AI Rasmlar** — Pollinations AI orqali
- 📊 **YouTube Upload** — Avtomatik yuklash
- 📈 **Statistika** — To'liq analitika

## 🎯 Niche'lar

- 🇺🇸 Horror English (Mr. Nightmare uslubi)
- 🇪🇸 Horror Spanish
- 📜 History English (Uncover History uslubi)
- 🇷🇺 War Russian (СМЕРШ uslubi)

## 🚀 Ishlatish

1. Google akkount bilan kiring
2. Niche tanlang
3. "Video Yaratish" bosing
4. 10-15 daqiqa kuting
5. Video YouTube'da tayyor!

## 💻 Texnologiyalar

- Frontend: Streamlit
- Backend: Python + FFmpeg
- AI: Gemini, Edge-TTS, Pollinations
- Auth: Firebase
- Database: Firestore
- Hosting: Streamlit Cloud
